Dork Watcher ヘルプ

🔍 Dork Watcherとは？

Google Dorkを使って、あなたのサイトに潜在的な情報漏洩がないかを確認するためのツールです。

📝 使い方

  1. ドメイン名を入力: 調査したいサイトのドメイン名（例: example.com）を入力してください。
  2. フィルターを選択: カテゴリー・リスク・演算子の3軸でDorkを絞り込めます。
  3. チェック開始: ボタンを押すとGoogle検索リンクが生成されます。
  4. 結果確認: 各リンクをクリックしてGoogle検索結果を確認してください。

⚠️ 重要な注意事項

  • 自分のサイトのみ調査してください - 他人のサイトを無断で調査することは避けてください。
  • 多くの場合、検索結果は空です - ただし、空振りだけで安全とは判断できません。
  • Google検索の制限 - 頻繁な検索はGoogleによって制限される場合があります。
  • 結果の解釈 - ヒットした場合でも、実際の脆弱性とは限りません。専門家による確認をおすすめします。

📊 カテゴリー説明

  • ファイル漏洩: .env、.sql、.logなどの機密ファイルの漏洩をチェック
  • 管理系: 管理画面やログインページの露出をチェック
  • 情報ワード: パスワードやAPIキーなどの機密情報をチェック
  • その他: ディレクトリリスティングやテストページなどをチェック

🎯 リスクレベル

  • High: 機密情報の漏洩に直結する可能性が高い
  • Medium: セキュリティ上の注意が必要
  • Low: 一般的な情報だが確認推奨

🔤 公式演算子と非公式演算子

Googleのヘルプに載っている演算子は""・site:・-・before:・after:・filetype:の6つです。

inurl:・intitle:・intext:・ext:は文書化されておらず、予告なく効かなくなることがあります。

「演算子の表記」を切り替えると、同じ狙いの検索を両方の書き方で試せます。結果が同じか確かめてください。

🧯 ヒットしたときの対処

  1. まず塞ぐ：公開を止める、またはアクセスを制限する。
  2. 漏れた前提で動く：認証情報を無効にして発行し直す。
  3. 検索結果から消す：非表示ツールと恒久的な削除を併用する。
  4. 原因を直す：配置やデプロイの手順を見直す。

🌗 テーマと言語の切り替え

右上のボタンでライトモード・ダークモードを切り替えできます。設定は自動保存されます。

その隣のボタンで日本語と英語を切り替えます。?lang=en付きで開くと保存内容より優先します。

🔍 What is Dork Watcher?

A tool to check your site for potential information leaks using Google Dorks.

📝 How to Use

  1. Enter Domain: Input the domain name you want to investigate (e.g., example.com).
  2. Select Filters: Filter Dorks by category, risk and operator support.
  3. Start Check: Click the button to generate Google search links.
  4. Review Results: Click each link to check Google search results.

⚠️ Important Notes

  • Investigate your own sites only - Never investigate someone else's site without permission.
  • Empty results are normal - Empty results alone do not prove the site is safe.
  • Google search limitations - Frequent searches may be restricted by Google.
  • Result interpretation - Hits don't necessarily indicate actual vulnerabilities. Expert verification is recommended.

📊 Category Descriptions

  • File leaks: Check for leaked sensitive files like .env, .sql, .log
  • Admin access: Check for exposed admin panels and login pages
  • Info keywords: Check for sensitive information like passwords and API keys
  • Others: Check for directory listings, test pages, etc.

🎯 Risk Levels

  • High: High possibility of direct sensitive information leakage
  • Medium: Requires security attention
  • Low: General information but recommended to check

🔤 Documented and undocumented operators

Google Help lists six operators: "", site:, -, before:, after: and filetype:.

inurl:, intitle:, intext: and ext: are undocumented and may stop working without notice.

Switch Operator style to generate both forms for the same search goal, and compare their results.

🧯 What to do after a hit

  1. Stop exposure: remove public access or restrict access.
  2. Assume exposure: revoke and reissue credentials.
  3. Remove search results: use Removals and permanent removal measures.
  4. Fix the cause: review deployment and file locations.

🌗 Theme and language

Use the button in the top right to switch between light and dark modes. Settings are saved automatically.

The button next to it switches Japanese and English. Opening with ?lang=ja overrides the saved value.
